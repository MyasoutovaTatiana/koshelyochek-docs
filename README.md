# Кошелёчек — публичная документация

Публичные пользовательские документы Telegram-бота «Кошелёчек».

Здесь публикуются документы, которые должны быть доступны пользователям без доступа к приватному репозиторию с кодом бота: уведомление об обработке данных, инструкции по экспорту и удалению данных и контакты поддержки.

Основной код продукта хранится отдельно в приватном репозитории `MyasoutovaTatiana/subscription-bot`.

Текущая задача публикации privacy notice связана с `MyasoutovaTatiana/subscription-bot#111`.
